# Playlist-Verwaltung für Digital-Signage-Bildschirme

*Schreibprobe: Benutzerhandbuch-Artikel*

## Überblick

Mit der **Playlist-Verwaltung** erstellen und planen Sie Inhalte für Ihr gesamtes Bildschirmnetzwerk zentral – von einzelnen Standorten bis hin zu ganzen Filialgruppen. Sie legen fest, welche Inhalte wann und auf welchen Bildschirmen angezeigt werden, ohne jeden Bildschirm einzeln konfigurieren zu müssen.

In diesem Artikel erfahren Sie, wie Sie eine Playlist erstellen, Inhalte zeitlich planen und Bildschirmgruppen zuweisen.

## Inhalte zentral verwalten und ausspielen

Bisher mussten Inhalte für jeden Bildschirm einzeln hochgeladen und zeitlich geplant werden. Bei größeren Bildschirmnetzwerken entstand dadurch ein erheblicher manueller Aufwand, insbesondere wenn sich Inhalte häufig ändern, z. B. bei saisonalen Angeboten oder Tagesaktionen.

Mit der Playlist-Verwaltung erstellen Sie eine Playlist einmal und weisen sie mehreren Bildschirmen oder Bildschirmgruppen gleichzeitig zu.

## Playlist-Verwaltung öffnen

1. Melden Sie sich am Verwaltungsportal an.
2. Wählen Sie **Inhalte** > **Playlist-Verwaltung**.

Wenn diese Option nicht angezeigt wird, wenden Sie sich an eine Person mit Administratorberechtigungen. Die Berechtigung **Playlist-Verwaltung (Bearbeiten)** muss unter **Einstellungen** > **Rollenberechtigungen** aktiviert sein.

## Eine Playlist erstellen

1. Wählen Sie **Neue Playlist**.
2. Geben Sie einen Namen und optional eine Beschreibung ein. So können Sie die Playlist später leichter wiederfinden.
3. Wählen Sie **Inhalt hinzufügen**, um Bilder, Videos oder Wegweiser aus der Mediathek auszuwählen.
4. Ordnen Sie die Inhalte durch Ziehen und Ablegen in der gewünschten Reihenfolge an.
5. Legen Sie für jedes Inhaltselement die Anzeigedauer fest, oder übernehmen Sie die Standarddauer für alle Elemente.
6. Wählen Sie **Speichern**.

## Inhalte zeitlich planen

Sie können festlegen, wann eine Playlist aktiv ist, statt sie dauerhaft wiederzugeben.

1. Öffnen Sie die gewünschte Playlist und wählen Sie **Zeitplan bearbeiten**.
2. Legen Sie ein Start- und Enddatum fest, oder wählen Sie **Unbefristet**, wenn die Playlist ohne Enddatum aktiv bleiben soll.
3. Optional können Sie die Anzeige auf bestimmte Wochentage oder Tageszeiten beschränken. Beispielsweise können Sie ein Mittagsangebot nur zwischen 11:00 und 14:00 Uhr anzeigen.
4. Wählen Sie **Zeitplan speichern**.

Wenn sich die Zeitpläne mehrerer Playlists überschneiden, zeigt der Bildschirm die Playlist mit der höheren Priorität an. Sie legen die Priorität in den Playlist-Einstellungen fest.

## Playlists Bildschirmen zuweisen

1. Öffnen Sie die gewünschte Playlist und wählen Sie **Bildschirme zuweisen**.
2. Wählen Sie einzelne Bildschirme aus, oder wählen Sie eine ganze **Bildschirmgruppe**, z. B. alle Bildschirme eines Filialstandorts.
3. Wählen Sie **Zuweisung übernehmen**.

Die Änderung wird nach der nächsten Synchronisierung auf den zugewiesenen Bildschirmen wirksam. Der Status jedes Bildschirms – **Aktualisiert**, **Ausstehend** oder **Offline** – wird in der Übersicht angezeigt.

## Tipps

- Erstellen Sie Bildschirmgruppen nach Standort oder Verwendungszweck, z. B. **Eingangsbereich** oder **Kassenbereich**. So können Sie Playlists künftig schneller zuweisen, ohne einzelne Bildschirme erneut auszuwählen.
- Nutzen Sie die Prioritätseinstellung gezielt für kurzfristige Aktionen. Eine hochpriorisierte Playlist mit begrenztem Zeitraum überschreibt automatisch die reguläre Playlist, ohne dass Sie diese vorübergehend deaktivieren müssen.
- Prüfen Sie den Bildschirmstatus nach einer Zuweisung, insbesondere bei Bildschirmen mit instabiler Netzwerkverbindung. Ein Bildschirm mit dem Status **Ausstehend** hat die neue Playlist möglicherweise noch nicht empfangen.

## Verwandte Themen

- Bildschirmgruppen erstellen und verwalten
- Inhalte in der Mediathek organisieren
- Bildschirmstatus und Fehlerbehebung
